# Alfred's Digital Workshop

A GitHub Pages site for hosting free developer tools and premium digital products.

## Structure

- `index.html` — Landing page
- `tools/` — Free micro-tools (HTML/JS, self-contained)
- Links to Gumroad for premium products

## Deployment

1. Create a GitHub repo (e.g. `alfreds-workshop`)
2. Push this directory
3. Enable GitHub Pages (Settings → Pages → Deploy from branch `main`)
4. Custom domain optional

## Local Preview

Just open `index.html` in a browser — no build step needed.
